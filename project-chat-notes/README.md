# Project Chat Notes

Purpose: keep a running, searchable history of project discussions, decisions, and follow-up actions.

## Structure
- `sessions/` contains one file per chat session.
- `SESSION_TEMPLATE.md` is the template for new sessions.

## Naming convention
Use date-first filenames so notes stay sorted:
- `sessions/YYYY-MM-DD.md`

## Recommended workflow
1. At the end of each chat, create or update today's session file.
2. Capture: context, decisions, phase/status updates, and next actions.
3. Link relevant files/commits when applicable.

## Quick start
- Copy `SESSION_TEMPLATE.md` to `sessions/<today>.md`
- Fill in the sections
